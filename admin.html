はじめに：ログインキーの登録（初回だけ）

この画面から投稿するために、「ログインキー」を1回だけ登録します。
登録したキーはこの端末にだけ保存されるので、次回からは何もせずに書けます。

この画面は検索には出ません。キーを持っている人だけが投稿できます。

キーをお持ちでない場合は、下の手順でご自身で作れます。

ログインキーの作り方

この先はGitHubという英語のサイトが開きます。 英語のままで正常です。押す場所だけ下でご案内しますので、そのとおりに進めてください。
  1. 下のボタンを押します。
    GitHubにログインしていない場合は、先にログイン画面が出ます。
    GitHubでキーを作る
  2. 「Expiration」の右にある選択欄を「No expiration」に変えます。
    Expiration＝有効期限／No expiration＝期限なし
    画面のイメージ
    Expiration No expiration ▾
    名前と権限は、はじめから入った状態で開きます。そのままで大丈夫です。
  3. いちばん下までスクロールして、緑色の「Generate token」ボタンを押します。
    Generate token＝キーを作る
    画面のイメージ
    Generate token
  4. ghp_ ではじまる長い文字列が出てきます。
    右側のコピーのマークを押してコピーし、この画面の上の欄に貼り付けて「登録して始める」を押してください。
    この文字列は一度閉じると二度と見られません。貼り付けるまでGitHubの画面は閉じないでください。

権限をこのホームページだけに限定したい方（上級者向け）
  1. こちらのページを開きます。
  2. Token name（キーの名前）に cargolex-blog と入力します。
  3. Repository access（対象の選択）で Only select repositories → konohito/cargolex-hp を選びます。
  4. Permissions → Repository permissions の Contents を Read and write（読み書き）にします。
  5. Generate token を押し、github_pat_… をコピーします。

ここに写真をドラッグ＆ドロップ

スマホなら「写真を選ぶ」からカメラロールを開けます。コピーした画像の貼り付けにも対応しています。
1枚目の写真が自動で「アイキャッチ（一覧に出る写真）」になります。変更したいときは写真の「アイキャッチ」を押してください。
詳しい設定（ふだんは触らなくて大丈夫です）
記事のアドレスに使われます。日本語は使えません。

公開ボタンを押すと、1〜2分でホームページに反映されます。
