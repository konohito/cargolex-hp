はじめに：接続キーの設定（初回のみ）

この画面から記事を投稿するために、GitHubの「接続キー」を1回だけ登録します。登録したキーはこの端末のブラウザにのみ保存され、外部には送信されません。

  1. こちらのページを開きます（GitHubにログインしてください）。
  2. Token name に cargolex-blog と入力します。
  3. Expiration（有効期限）で No expiration または長めの期間を選びます。
  4. Repository access で Only select repositories を選び、konohito/cargolex-hp を選びます。
  5. Permissions → Repository permissions の中の Contents を Read and write にします。
  6. 一番下の Generate token を押し、表示された github_pat_… をコピーします。
  7. 下の欄に貼り付けて「保存して接続する」を押してください。
この画面は検索エンジンに載りません。キーを知らない人は投稿できません。
記事のアドレスに使われます。日本語は使えません。空欄なら自動でつけます。
スマホの写真でOKです。自動で軽くしてからアップロードします。

公開ボタンを押すと、1〜2分でホームページに反映されます。
